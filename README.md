An integrated IoT robotics platform featuring an ESP32-controlled mobile robot with a Node-RED dashboard for real-time navigation, telemetry logging, and secure access control.  🚀 Project OverviewThis project addresses the challenge of enabling an embedded robotic system to perform real-time classification using a scanning ultrasonic array. The dashboard allows the user to log in, send movement commands, monitor robot status, and record distance readings.  ✨ Key FeaturesSecure Access: A login flow prevents access to robot controls until credentials (admin/1234) are verified.  Real-Time Monitoring: Live distance charting and robot status updates via serial communication.  Data Logging: Automatically appends time-stamped distance readings to robot_data.csv.  Intelligent Mitigation: Maps NaN sensor readings to MAX_SENSE_RANGE (400 cm) to treat null readings as a "Clear Path" instead of an obstacle.  🛠️ Hardware ComponentsMicrocontroller: ESP32 DevKitV1.  Motor Driver: L298N dual H-bridge.  Sensor: HC-SR04 ultrasonic distance sensor.  Actuator: SG90 servo motor for 180-degree scanning.  Chassis: 2WD acrylic robot chassis with front caster wheel.  💻 Software StackDashboard: Node-RED using node-red-dashboard and node-red-node-serialport.  Communication: Serial communication on COM10 at 115200 baud.  Data Processing: * PCA: Spatial feature compression.  Wavelet Transform: Edge detection and noise filtering.  📊 Performance ResultsThe system classifies environments into three categories: Clear Path, Linear Obstacle, and Corner or Complex Obstacle.
